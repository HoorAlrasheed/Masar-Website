Design a complete, modern and professional Arabic website for “Masar Initiative” (مبادرة مسار), a student initiative affiliated with the Robotics Club at Imam Mohammad Ibn Saud Islamic University in Saudi Arabia.

The website should be designed as a real, polished university initiative platform, not as a simple student project.

Overall Design Direction

Create a visual identity that feels:

Elegant
Classic and sophisticated
Clean and minimal
Modern but timeless
Professional and trustworthy
Organized and easy to navigate
Suitable for a university initiative
Visually impressive without being flashy

Use a refined and harmonious color palette. Prefer elegant deep neutral tones combined with a subtle accent color. Avoid overly bright, childish, playful, or excessive colors.

Use generous white space, strong typography hierarchy, clean grids, subtle borders, elegant cards, and consistent spacing.

The Arabic interface should be RTL (Right-to-Left).

Use a beautiful Arabic font pairing with excellent readability. Headings should feel distinctive and premium while body text remains simple and highly readable.

The design should feel similar in quality to a professional modern university or educational platform.

Make the entire website consistent.

Use:

Responsive desktop design
Responsive mobile design
Consistent spacing system
Consistent button styles
Consistent card components
Consistent typography
Clear hierarchy
Accessible contrast
Subtle hover states
Very subtle animations/micro-interactions
Elegant transitions

Avoid:

Excessive gradients
Neon colors
Excessive shadows
Cartoon illustrations
Overly rounded childish cards
Crowded layouts
Too many colors
Excessive animations

The final design should communicate:

مسار = معرفة + توجيه + فرص + مجتمع طلابي

The overall impression should be premium, elegant, academic, modern, trustworthy, and inspiring.

Design the website as a complete design system with reusable components so that additional pages, programs, news articles, resources, and team members can be added later without changing the visual identity.

Start by creating the homepage and main design system, then use the same visual language throughout all other pages
